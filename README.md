# Multi-Factor-AI-Stock-Forcasting-Model
Multi-Factor AI Stock Forecasting Model analyzes short-term stock movements using Polygon.io data with a 15-minute delay. Models are trained in Python and deployed through a low-latency C++ engine, with a web interface built in HTML, CSS, and JavaScript. Forecasts are generated for 1, 5, 30, and 60-minute intervals.
